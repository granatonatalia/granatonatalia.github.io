# Changelog

Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

O formato é baseado em [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/),
e este projeto adere ao [Versionamento Semântico](https://semver.org/lang/pt-BR/).

## [1.0.0] - 2026-01-08

### Adicionado
- Site de portfolio pessoal com design moderno e minimalista
- Design totalmente responsivo para todos os dispositivos
- Toggle entre modo claro e escuro com persistência de preferência
- Controles de acessibilidade para ajuste de tamanho de fonte (4 níveis)
- Animações suaves baseadas em scroll usando Intersection Observer
- Seções principais:
  - Sobre: Apresentação profissional
  - Experiência: Histórico de trabalho
  - Habilidades: Competências técnicas (Frontend e Backend)
  - Projetos: Portfolio de projetos
  - Educação: Formação acadêmica
- SEO otimizado com meta tags Open Graph e Twitter Cards
- Favicon customizado em SVG
- CSS com variáveis customizadas para fácil personalização de tema
- JavaScript vanilla (ES6+) sem dependências externas
- Integração com GitHub Pages
- Domínio customizado (nataliagranato.me)
